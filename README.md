# jakkie

You found my GitHub. Congrats, or condolences.

I work on navigation, at every level. From the signal up: raw GNSS samples turned into a position by a receiver I'm writing myself. Then inertial navigation and sensor fusion for when that position goes away. Then drones and swarms that keep working without it. Next stop is space, to see what an INS can do in orbit, where the accelerometer reads zero and "down" is a matter of opinion. I'm also doing a PhD on cooperative navigation, which is the same problem with more paperwork.

Mostly Rust, because I like my bugs caught at compile time and my segfaults theoretical. I write the maths by hand until it stops lying to me. In a past life I did data infrastructure, so I still think every problem is a time series. I'm usually right.

    position ........ known, roughly
    uncertainty ..... growing
    calibration ..... pending since August
    orbit ........... not yet
    coffee .......... nominal
    sleep ........... scheduled for after the PhD

Stuff goes public when it works, which keeps this page tidy.
